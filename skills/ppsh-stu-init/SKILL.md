# 學生專案初始化

為學生的專案資料夾做四件事：

| 做什麼 | 產出 | 比喻 |
|---|---|---|
| 建專案藍圖 | `AGENTS.md`（目的、規則、作業成果放哪） | 班級公約 |
| 建交接檔 | `handoff.md`（上次做到哪、下一步） | 作業進度本 |
| 建橋接檔 | `CLAUDE.md`（只有一行 `@AGENTS.md`） | — |
| 建成果資料夾 | `作業成果\`（含 圖片、影片、文件） | 作業繳交櫃 |

另外還會**檢查電腦環境**，告訴學生「能不能生圖、能不能寫學習歷程報告」。

**不碰 git、不上傳任何東西、不下載任何模型或軟體。**

## 1. 先確認資料夾

1. 以**目前的工作資料夾**當專案資料夾，把完整路徑念給學生確認。
2. **不要在這些地方建專案**：磁碟根目錄（如 `C:\`）、桌面本身、使用者家目錄本身、`Windows`、`Program Files`。遇到就請學生先建一個專屬的新資料夾（例如 `D:\作業\我的AI專案`），請老師或學生在 Codex 重新選那個資料夾開啟，**不要自己搬檔案**。
3. 檢查是否已經有 `AGENTS.md`、`handoff.md`、`CLAUDE.md`。**有的話絕對不要覆蓋**，改問學生：「要更新內容」還是「保留不動」。

## 2. 訪談（一次問完，不要一題一題來回）

用一則訊息問完，沒答的先寫「待補」：

1. 這個專案叫什麼名字？一句話說明要做什麼？
2. 你的**班級與座號**（例如「高一3班 15號」）。**不要問姓名，也不要寫姓名。**
3. 這次想做什麼？（生圖／生影片／兩個都要／還沒想好）
4. 有沒有期限（例如要交的日期）？

## 3. 建立成果資料夾

在專案資料夾下建立（已存在就跳過，不要刪、不要改裡面的檔案）：

```
作業成果\
├─ 圖片\
├─ 影片\
└─ 文件\
```

## 4. 環境檢查

執行本技能資料夾內的 `scripts/check_env.py`（只讀，不安裝、不改檔案）。Windows 用 `python`，不行再試 `py -3`。

把結果用**白話繁體中文**整理成下表回報，不要貼原始輸出：

| 項目 | 狀態 | 意思 |
|---|---|---|
| 讀取 PDF 的套件 | ✅／❌ | 沒有的話，學習歷程報告無法讀 PDF 資料 |
| 寫入 Word 的套件（python-docx） | ✅／❌ | 沒有的話，無法產生學習歷程報告 .docx |
| ComfyUI 安裝／連線 | ✅／未偵測 | 有沒有裝在這台、連線埠 8188 有沒有開 |
| 生圖模型 | ✅（列出檔名）／❌ | ComfyUI 裡有沒有 checkpoints／diffusion_models／unet 模型檔 |

處理規則：

- **缺 Python 套件** → 說明用途，**問學生同意**後才安裝（`python -m pip install python-docx pymupdf`）。安裝失敗（網路、權限）就停下，用白話回報，請學生找老師，**不要換別的方法硬裝**。
- **沒有 ComfyUI、沒有模型、連不上** → 告訴學生「這不影響你學習，生圖可以先用 Codex 內建的生圖功能；ComfyUI 的使用方式請問老師」。**不要自己去網路下載模型或安裝 ComfyUI**（檔案很大、來源不可信）。
- **有 ComfyUI 但沒有生圖模型** → 回報「裝好了但還沒有模型」，請學生告訴老師，同樣不要自己下載。
- Codex 內建生圖能不能用，這個腳本**檢查不出來**：回報時註明「請在 Codex 試一次生圖才知道」。
- 若環境變數 `COMFYUI_URL` 有設定，腳本會用它當連線位址（例如學校主機）；沒設定就檢查本機 `http://127.0.0.1:8188`。

## 5. 建立 AGENTS.md

寫在專案資料夾根目錄，UTF-8：

```markdown
# <專案名稱>

> <一句話目的>
> 建立日期：YYYY-MM-DD ｜ 班級座號：<高一3班 15號>

## 這次要做
- <生圖／生影片／其他>

## 重要規則（AI 每次都要遵守）
1. **所有生成的圖片、影片、文件，一律存到 `作業成果\` 資料夾**（圖片放 `圖片\`、影片放 `影片\`、文件放 `文件\`）。不要存在其他地方。
2. 每次生成後，告訴我檔案存在哪裡、檔名是什麼。
3. 檔名用「日期＿主題」，例如 `20261007_戴眼鏡的貓.png`，不要覆蓋舊檔。
4. 不要把我的 Token、密碼、班級密碼寫進任何檔案或對話。
5. 檔案裡提到人時，只寫班級與座號，不寫姓名；不要用同學或老師的臉當生成素材。

## 時程
| 節點 | 日期 | 狀態 |
|------|------|------|
| <節點> | <日期或待補> | ⬜ |

## 環境檢查結果（<日期>）
- 讀 PDF：<✅／❌>　寫 Word：<✅／❌>
- ComfyUI：<狀態>　生圖模型：<狀態>

## 資料夾結構
作業成果\（圖片、影片、文件）
```

## 6. 建立 handoff.md

```markdown
# 交接檔：<專案名稱>

**最後更新**：YYYY-MM-DD HH:MM ｜ <電腦名稱>

## 上次做到哪
專案剛初始化，尚未開始。

## 下一步
1. <從訪談推出的第一個動作，例如「用 Codex 生第一張圖」>

## 卡關／待決
<環境檢查缺什麼要問老師；沒有就寫「無」>

## 變更紀錄
- YYYY-MM-DD <電腦名稱>：初始化專案
```

時間與電腦名稱**一定要實際執行指令取得**：電腦名稱用 `hostname`；時間用 PowerShell `Get-Date -Format "yyyy-MM-dd HH:mm"`。不可寫「待補」。

## 7. 建立 CLAUDE.md（只有一行）

```markdown
@AGENTS.md
```

已存在就不覆蓋；不要把 `AGENTS.md` 的內容複製進去；不要匯入 `handoff.md`。

## 8. 完成回報

```
專案初始化完成
  專案資料夾：<完整路徑>
  已建立：AGENTS.md、handoff.md、CLAUDE.md、作業成果\（圖片／影片／文件）
  環境檢查：<讀PDF ✅／寫Word ✅／ComfyUI 未偵測／模型 ❌>
  需要問老師的：<有才寫>
  下一步：<handoff.md 第一項>
  → 之後說「開工」我會讀交接檔；說「收工」我會更新它；做完想寫學習歷程就說「寫學習歷程報告」
```

## 不要做的事

- 不要覆蓋已存在的 `AGENTS.md`、`handoff.md`、`CLAUDE.md`
- 不要執行 git、不要上傳、不要下載模型或軟體
- 不要把姓名、Token、密碼寫進任何檔案
- 不要搬動或刪除學生的任何檔案
