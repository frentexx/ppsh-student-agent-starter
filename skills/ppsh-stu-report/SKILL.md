# 學習歷程報告

把學生這個專案做過的事，整理成一份 Word（.docx）報告，內容來自三個地方：

| 來源 | 用途 |
|---|---|
| `作業成果\` 的圖片、影片、文件 | 成果展示 |
| Codex 對話歷程（指令與修改過程） | 學習歷程、「我下的指令」 |
| 學生口述的幾句省思 | 學習省思（AI 代寫，**學生同意才寫入**） |

## 三條硬規則

1. **只寫真的發生過的事。** 內容必須來自對話紀錄、檔案、學生說的話。不編造過程、不誇大成果、不替學生宣稱他沒說過的收穫。
2. **學習省思必須經學生同意才寫入。** 先給草稿、問「同意這樣寫嗎？」，學生明確說好才進報告。
3. **只寫班級與座號，不寫姓名**；Token、密碼、班級密碼一律不出現。

## 步驟

### 1. 找專案、盤點成果

1. 找目前工作資料夾（或上一層）的 `AGENTS.md`，讀專案目的與班級座號。找不到就請學生先說「初始化專案」。
2. 列出 `作業成果\` 的檔案（圖片、影片、文件各幾個、檔名、日期）。**是空的就停下**：告訴學生還沒有成果可以寫，建議先去做。
3. 一次問清楚（不要一題一題來回）：
   - 老師有沒有指定**報告範本或字數**？有的話請學生放進 `作業成果\文件\` 或貼上，章節以範本為準。
   - 要放進報告的成果：預設放**全部圖片**（最多約 8 張，超過請學生挑）；影片只列檔名。

### 2. 取得對話歷程

1. 執行本技能資料夾內的 `scripts/extract_history.py --project <專案資料夾>`。它會讀 Codex 的本機會話紀錄，只取**這個專案**的對話，**自動遮蔽金鑰與密碼**，輸出 `作業成果\對話紀錄.md`。
2. 讀 `對話紀錄.md`。
3. 若腳本結束碼為 2（找不到紀錄）：請學生把**最重要的幾次指令與結果**貼在對話裡，或口述；你整理成 `作業成果\對話紀錄.md`。若提示缺少 `zstandard` 套件，**問學生同意後**才用 `python -m pip install zstandard` 安裝。
4. 讀完後檢查有沒有姓名、學號、電話；有的話在報告裡改成班級座號或略過。

> 狀態：Codex 會話紀錄的格式依公開資料撰寫，【待實機驗證】；腳本失敗不要硬猜，直接走第 3 點。

### 3. 整理草稿（先在對話裡給學生看）

用對話紀錄與檔案整理出，並用條列給學生看：

- **成果簡述**（約 100 字）
- **學習動機與目標**：來自 `AGENTS.md` 的目的與學生第一次下的需求
- **學習歷程**（3–6 個步驟）：每步包含
  - 標題
  - **我下的指令**：照學生原話引用，不改寫
  - 做了什麼、結果如何；若學生有**修改指令後變好**的地方，要特別寫出來（這是最能呈現學習的地方）
- **成果展示**：每個檔案配一句圖說。圖說若是你推測的，標出來請學生確認

### 4. 學習省思（AI 代寫，學生同意才寫入）

1. 用**一則訊息**問學生三個小問題，回答一兩句話就好：
   - 這次最有趣或最困難的是什麼？
   - 你怎麼解決，或下次想怎麼改？
   - 你學到了什麼？
2. 依學生的回答，用**第一人稱、高中生的口吻**寫成一到兩段（約 150–300 字）。
   - 用學生自己說的想法與用詞，**不補學生沒說的收穫**。
   - 學生答得很短就寫短，不要灌水。
3. 把草稿貼給學生，問：「**這樣寫你同意嗎？要改哪裡？**」
4. 學生要改就改，改完再問一次。**只有學生明確同意**（說好、可以、同意）才進報告。
5. 學生不想用 AI 寫，就直接用他自己的原句。

### 5. 產生 Word

1. 確認電腦能寫 Word：能 `import docx`。沒有就**問學生同意**後安裝（`python -m pip install python-docx`），失敗就停下請學生找老師。
2. 把內容寫成 JSON（欄位見 `scripts/build_report.py` 檔頭說明），存到 `作業成果\文件\學習歷程報告_spec.json`。
3. 執行 `scripts/build_report.py <spec.json> --project <專案資料夾>`。輸出 `作業成果\文件\學習歷程報告.docx`；若檔案已存在，**換個檔名（加日期），不要覆蓋**。
4. 報告最後會自動附「AI 使用說明」（圖片或影片由 AI 生成、使用的工具與指令、文字經學生同意）。這是誠實揭露，**不要拿掉**。

### 6. 回報

```
學習歷程報告完成
  檔案：作業成果\文件\<檔名>.docx
  內容：成果簡述、學習動機、學習歷程 <n> 步、成果 <n> 件、學習省思（已經你同意）
  請你：用 Word 打開從頭看一遍，確認沒有不對的地方再交
  提醒：對話紀錄.md 在作業成果裡，不一定要交；裡面若有你不想給人看的內容，不要一起交
```

## 不要做的事

- 不要在學生同意前把省思寫進 Word
- 不要編造對話裡沒有的過程、成果或心得
- 不要在報告或對話紀錄裡留下 Token、密碼、姓名
- 不要覆蓋學生既有的報告檔
- 不要把報告或對話上傳到任何地方

## 相關技能

- 專案起始：`ppsh-stu-init`（會檢查有沒有寫 Word 的套件）　收工：`ppsh-stu-shutdown`
