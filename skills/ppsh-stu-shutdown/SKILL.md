# 學生收工

目的：把今天的進度寫成**下一次（或換一台電腦）30 秒看得懂的交接**。

**不碰 git，不上傳任何東西。**

## 步驟

### 1. 找到專案

找目前工作資料夾（或往上一層）的 `AGENTS.md`。找不到就問學生專案在哪，**不要自己建新的**。

### 2. 回顧這次做了什麼

根據**這次對話的實際內容**整理，不要反問學生「你做了什麼」——你自己知道。整理成三件事：

- 完成了什麼（具體到檔名，例如 `作業成果\圖片\20261007_戴眼鏡的貓.png`）
- 還沒完成、做到一半的
- 發現的問題，或需要問老師的事

### 3. 檢查生成檔有沒有放對地方（只提醒，不搬動）

這次對話裡如果生成過圖片、影片或文件，確認它們都在 `作業成果\` 裡。若有檔案放在別的地方，**只告訴學生檔案在哪、應該放哪**，由學生決定要不要請你移動；**不要自己搬或刪**。

### 4. 更新 AGENTS.md（只在真的有變動時）

時程表狀態、資料夾結構、新發現的規則。沒變動就**不要動**。

### 5. 改寫 handoff.md（整份重寫，不是往下追加）

- **最後更新**：現在時間＋電腦名稱，**一定要實際執行指令取得**：`hostname`；時間用 PowerShell `Get-Date -Format "yyyy-MM-dd HH:mm"`
- **上次做到哪**：具體，寫「生了 3 張貓的圖，第 2 張眼鏡顏色不對」，不要寫「做了一些東西」
- **下一步**：1–3 項，可以直接動手的動作
- **卡關／待決**：要問老師的事；沒有就寫「無」
- **變更紀錄**：最上面加一行今天的，**只保留最近 5 筆**

### 6. 個資與金鑰提醒

掃一下這次有沒有出現：

- 學生姓名、學號、電話 → 提醒只留班級＋座號
- Token、密碼、班級密碼 → 提醒不可寫進檔案；如果已經寫進去，**叫學生立刻告訴老師**

沒有就不用講。

### 7. 回報

```
收工完成
  AGENTS.md：<已更新／無變動>
  handoff.md：已更新（<電腦名稱>）
  今天完成：<一兩句>
  作業成果：<新增 n 個檔案，都在作業成果裡／有 n 個不在，位置：…>
  下次接手：<下一步第一項>
  提醒：<個資或金鑰，沒有就省略>
  → 如果這個專案要交學習歷程，可以說「寫學習歷程報告」
```

## 不要做的事

- 不要執行 git commit／push
- 不要把 `handoff.md` 寫成流水帳
- 不要刪除或搬動學生的任何檔案
