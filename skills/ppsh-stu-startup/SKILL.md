# 學生開工

目的：學生在**任何一台電腦、任何一個新對話**坐下來，30 秒內知道上次做到哪、現在該做什麼。

## 步驟

### 1. 找到專案

看目前工作資料夾有沒有 `AGENTS.md`。

- **有** → 就是這個專案
- **沒有** → 往上一層找一次
- **還是沒有** → 告訴學生「這個資料夾還沒初始化」，問要不要先說「初始化專案」（`ppsh-stu-init`）。**不要自己編一份。**

### 2. 只讀兩份檔案

- `AGENTS.md` → 目的、規則、時程
- `handoff.md` → 上次做到哪、下一步、卡關

**只讀這兩份，不要一開場就掃整個資料夾。**

### 3. 看一眼作業成果（只數數，不讀內容）

列出 `作業成果\` 底下 圖片、影片、文件 各有幾個檔案，以及最新一個檔案的名稱與日期。資料夾不存在就提醒「還沒有作業成果資料夾，可以說『初始化專案』補建」。

### 4. 檢查是不是換了電腦

比對 `handoff.md` 的「最後更新」電腦名稱與目前這台（執行 `hostname`）。**不同台**就說「上次是在 <某台> 做的」，並提醒：檔案要在同一個資料夾（雲端硬碟或隨身碟）才接得上，**請確認作業成果資料夾也一起帶過來**。同一台就不用提。

### 5. 看時程

對照 `AGENTS.md` 的時程表與今天日期，**7 天內到期且未完成**的節點主動提出來。

### 6. 回報（簡短）

```
專案：<名稱>
上次：<電腦名稱>，<日期>
做到：<一兩句>
作業成果：圖片 <n>、影片 <n>、文件 <n>（最新：<檔名>）
下一步：
  1. <動作>
卡關：<有才寫>
時程提醒：<7 天內到期的節點，沒有就省略>
```

回報完**停下來等學生指示**，不要自動開始做下一步。

## 不要做的事

- 不要修改任何檔案（開工只讀）
- 不要執行 git
- 找不到 `handoff.md` 時不要自己編，改建議先初始化

## 相關技能

- 初始化：`ppsh-stu-init`　收工：`ppsh-stu-shutdown`
