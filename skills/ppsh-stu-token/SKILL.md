# 領取與切換點數（NMKING AI Gateway）

學生上課時，Codex 要改用**老師開的專案點數池**；下課後再切回**自己的個人設定**。這個技能陪學生一步一步走完，**由學生自己在瀏覽器與檔案總管操作**，你負責說明、提醒、檢查。

> 本文依平台分享者手冊 v2.6（2026-09-26）第 10、11 章與檢查清單整理。平台畫面會更新，**以學生當下看到的畫面為準**；Codex 端的實際畫面標為【待實測】。

## 鐵則（先講給學生聽）

1. **Token、設定 ZIP、班級密碼，都不要貼進對話、群組或截圖給別人。** 截圖要遮住完整 Token。
2. **每個人用自己的 Token，不交換、不借用。** 換人用會讓用量算錯人。
3. 你（AI）**不要索取、不要顯示**任何 Token 或密碼；學生要輸入班級密碼時，叫他自己在網頁上輸入，你不用看。
4. 班級密碼由老師**口頭或黑板**告訴學生；你不知道、也不要猜。
5. 套用設定會**改動 Codex 的連線設定**。動手前先請學生**存好手上的工作**。

## A. 領取（第一次上課）

請學生依序做，每做完一步回報「好了」再往下：

1. 用 Chrome 或 Edge 開**老師給的領取連結**。
2. 確認頁面顯示的是**本次課程**的名稱（不是別堂課）。
3. 選**免登入領取**：
   - 「識別名稱」照老師約定的格式填（例如座號，**不要填姓名**）。
   - 「班級密碼」向老師要，輸入在網頁欄位裡。
4. 領取成功後，**核對三件事**：點數池名稱、模型、有效時間。對不上就停下來問老師。
5. **不要換瀏覽器、不要清除瀏覽器資料。** 免登入領取沒有復原碼；換電腦或清除 Cookie 後，不能假設還打得開同一份設定。
6. 點「下載設定 ZIP」，選 **Windows** 版，只下載**自己的**那一份。

## B. 套用設定（把 Codex 接到專案點數池）

1. 請學生**先存好工作**（作業成果資料夾裡的檔案都在原位）。
2. 把 ZIP 解壓縮到一個資料夾（右鍵 → 全部解壓縮）。**不要在壓縮檔裡直接雙擊執行。**
3. 先讀 ZIP 裡的說明檔，再**雙擊「1-套用-NMKING-Codex.bat」**。看到成功訊息才算完成。
   - 這一步由**學生自己雙擊**，你不要替他執行。
   - 如果跳出「Windows 已保護您的電腦」之類的警告，請學生**問老師**，不要自己繞過。
4. 把 Codex **整個關掉**（包含右下角工作列的背景程式），再重新打開。
5. **建立新任務**。（只重開視窗不一定夠，舊任務可能還記著舊設定。）
6. 在新任務說「**開工**」接回進度。

## C. 確認真的接到專案點數池

在**新任務**裡確認三項：**目前提供者、點數池、模型** 都是這堂課的。方法依序：

1. 請學生在 Codex 的設定或模型畫面核對【待實測：實際位置】。
2. 讓學生傳一句簡單的話（例如「回覆 OK 兩個字」），能正常回答就代表連得上。
3. 若你需要自己確認，**只能**用過濾方式讀取 `%USERPROFILE%\.codex\config.toml` 中的 `model_provider`、`model`、`base_url` 三個欄位，**不得顯示整份檔案，也不得讀取或顯示任何含 key、token、secret、auth 的內容**。拿不準就不要讀，改請學生看畫面。

## D. 課後切回個人設定

1. 先**存好工作**。
2. 到當初解壓縮的資料夾，**雙擊「2-復原」**（檔名開頭是 `2-`，Windows 版為 .bat）。由學生自己執行。
3. 把 Codex 整個關掉再重開，**建立新任務**。
4. 照 C 的方法確認已經回到個人設定。

> 還沒下課前不要切回個人設定：個人帳號的額度不是拿來上課用的。

## E. 換到另一個點數池（另一堂課或另一個專案）

1. 先問清楚**現在要用哪一個池**（課程名稱）。
2. 到**那個池**的領取頁領取，下載**那個池**的設定 ZIP。**不要重複套用舊的 ZIP。**
3. 照 B 套用、照 C 確認。
4. 之後想回個人設定，一樣用 D。

## 常見狀況（簡短）

| 症狀 | 先做什麼 |
|---|---|
| 領不到 | 確認連結是本次課程、識別名稱格式、班級密碼（問老師）；老師可能已停止加入 |
| 領到了但不能用 | 可能超出有效日期或上課時段，或個人額度用完；**記下時間與錯誤文字**，告訴老師 |
| Codex 還在用舊設定 | 完全關閉後**建立新任務**，不是只重開視窗 |
| 設定工具跑不起來 | 確認有解壓縮、檔案是自己的；**不要下載別人的 ZIP 來用**；把作業系統、時間、簡短訊息記下來給老師 |
| 想看自己用了多少 | 到平台「我的 Token」查看個人用量【待實測】 |

給老師回報問題時，只提供**時間、點數池名稱、做了什麼、錯誤訊息**，**絕不附上完整 Token 或含 Token 的 ZIP**。

## 不要做的事

- 不要要求、記錄、複述任何 Token、設定 ZIP 內容、班級密碼
- 不要替學生執行 `.bat` 套用或復原
- 不要建議用別人的設定檔排除問題
- 不要自己改 `config.toml` 或任何 Codex 設定
